# Security

Please do not report security vulnerabilities in public issues. Email Red Hat
Product Security at secalert@redhat.com; see
https://access.redhat.com/security/team/contact for details and PGP keys.

How the reconciler handles credentials and untrusted input is described in the
[Security notes](README.md#security-notes) and in
[docs/DESIGN.md](docs/DESIGN.md#security-and-operations).
